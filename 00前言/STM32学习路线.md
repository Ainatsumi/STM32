# STM32 学习路线 · 从点灯到能写项目

> 目标芯片 **STM32F103C8T6**（72 MHz / 64 KB Flash / 20 KB RAM）
> 工具链 **STM32CubeMX + CMake + arm-none-eabi-gcc + VS Code + ST-Link**
> 代码风格 **HAL 库**（不是标准库 SPL）
> 参考资料 **江协科技 STM32 教程**（概念）+ 本仓库自己的 HAL 实现（代码）

---

## 这份大纲怎么用

- 每个实验一节，含 **目标 / 硬件 / 知识点 / 验收标准** 四项
- 复选框打勾表示完成，可以配合 GitHub 的 Issue 或 Projects 使用

## 最终能力

学完应该有这些能力：

1. 拿到任何 CubeMX 工程，能看懂 `main.c` 在干什么
2. 独立配置 GPIO / EXTI / TIM / ADC / DMA / USART / I2C 七大类外设
3. 会写中断和 DMA，知道什么时候该用、什么时候不该用
4. 能读传感器数据手册，自己写出驱动
5. 程序"不工作"时，有一套排查顺序，而不是乱改

- [ ] 4.1 定时中断

- [ ] 4.6 输入捕获测频率
- [ ] 4.7 PWMI 测频率和占空比
- [ ] 4.8 编码器接口测速

**两个必须背下来的公式**：

```
定时周期  T = (PSC + 1) × (ARR + 1) / 72MHz
PWM 频率  f = 72MHz / ((PSC + 1) × (ARR + 1))
占空比    = CCR / (ARR + 1)
```

**这一阶段要真正搞懂**：

- PSC 是"分频"（把 72MHz 变慢），ARR 是"数到多少重来"
- 为什么舵机要 50Hz？脉宽 0.5ms→0°、1.5ms→90°、2.5ms→180°
- 输入捕获和 PWM 输出用的是同一个定时器的不同通道，但方向相反

**验收**：能让 LED 从暗到亮再到暗（呼吸灯），能让舵机转到指定角度。

## 每个实验的标准流程

1. **看原理** —— 江协科技对应视频，理解这个外设在干什么
2. **读参考代码** —— `experiment\所有的实验打包\` 下的 SPL 版本，看它怎么操作寄存器
3. **CubeMX 配置** —— 用图形界面配出等价的 HAL 设置
4. **写代码** —— 先跑通最小版本，再加功能
5. **验证现象** —— 和预期不符时，按「排查顺序」走
6. **写笔记** —— 记录踩的坑，这是最有价值的部分
7. **commit** —— 一个实验一个提交

## 程序不工作时的排查顺序

按这个顺序，不要跳步：

1. **编译过了吗？** 有没有 warning 被忽略
2. **烧进去了吗？** `.bin`/`.elf` 的时间戳是不是刚才的
3. **时钟开了吗？** 外设对应的 `__HAL_RCC_XXX_CLK_ENABLE()`
4. **引脚对吗？** CubeMX 里配的引脚和实际接线是否一致
5. **模式对吗？** 输入/输出/复用/模拟
6. **电平对吗？** 万用表量一下，别靠猜
7. **中断开了吗？** NVIC 里勾了吗，`HAL_NVIC_EnableIRQ` 调用了吗
8. **优先级对吗？** 有没有在高优先级 ISR 里等低优先级中断

## 为什么这样排（和江协科技原版的差异）

| 调整 | 原因 |
|---|---|
| **串口从第 9 章提到第 2 阶段** | 调试手段越早具备越好。没有打印能力，后面每个实验都只能靠猜 |
| **OLED 从第 4 章挪到第 5 阶段** | OLED 本质是 I2C 应用，等 GPIO 和中断都熟了再学更顺 |
| **ADC 和 DMA 分成两阶段** | 江科大把 DMA+ADC 放一起，容易搅混。先单独学 DMA 搬运，再组合 |
| **加了「状态机解析」** | 江科大的 9-4 只讲了固定格式，实际工程里不定长数据更常见 |
| **加了「阶段 10 综合项目」** | 前面都是单点技能，不做项目串不起来 |

**没变的**：整体还是「GPIO → 中断 → 定时器 → 通信 → 传感器」这条主脉络，和江协科技一致。

## 学习节奏

- 阶段 1~3：**每个实验 1~2 小时**，重点是理解概念
- 阶段 4：**每个实验 2~4 小时**，定时器是最难的一章，别急
- 阶段 5~7：**每个实验 1~2 小时**，概念清楚了就快
- 阶段 8~9：**每个实验 2~3 小时**，协议和传感器需要耐心
- 阶段 10：**1~2 周**

**不要跳阶段**。定时器没搞懂就学 DMA，会一直卡。
